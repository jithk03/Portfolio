# Onshape Self-Study: Introduction to Parametric Feature-Based CAD

**Course:** Digital Design and Fabrication (inf175)
**Program:** Media Informatics and Multimedia Systems, Carl von Ossietzky Universität Oldenburg
**Date:** June 2026

## Overview

As part of the Digital Design and Fabrication course, this self-study session replaced an in-person class with a set of guided online courses on **Onshape**, a free, cloud-based, parametric CAD system. The goal was to build foundational knowledge of parametric, feature-based CAD modeling ahead of hands-on design work later in the course.

## Courses Completed

| Course | Duration | Description |
|---|---|---|
| Introduction to Parametric Feature-Based CAD | 15 min | Core principles of modeling in a parametric, feature-based CAD system |
| Introduction to Sketching | 1 h | Fundamentals of 2D sketching as the basis for 3D features in Onshape |
| Introduction to Part Studios | 2 h | Working with Onshape's Part Studio environment and modeling tools |

## What I Learned

- **Parametric modeling fundamentals** — how features are built sequentially on top of one another, and how changing an early parameter (e.g. a sketch dimension) propagates through the entire model history.
- **Sketching basics** — creating constrained 2D sketches (lines, dimensions, relations) that serve as the foundation for 3D features like extrudes and revolves.
- **Part Studio workflow** — navigating Onshape's cloud-based modeling environment, organizing features in the timeline, and using core tools to build a complete part.

## Reflection

This self-study session served as a low-overhead but effective onboarding into parametric CAD concepts. Learning Onshape's feature-based approach — rather than direct modeling — reinforces a design mindset centered on editable, traceable design history, which is foundational for later, more complex modeling tasks in the course.
